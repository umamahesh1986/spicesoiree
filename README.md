# Spice Soirée

Spice Soirée is a browser-based React app. `src/App.js` is the route/component
shell; `src/components` contains the header, footer, home hero, restaurant menu,
and independently styled menu/content sections.

## Run the app

1. Install dependencies with `npm install`.
2. Start the browser development server with `npm start`.
3. Open the local URL printed by the server.
4. Create a production build with `npm run build`.

The booking form can add delivery dates, request the browser's location, and prepare an order in WhatsApp.

The app uses React Router and CRACO; it does not use Vite or Expo.

The home page navigation targets `#dining`, `#scheduler`, `#hospitality`,
`#experiences`, and `#reviews`.
